요청하신 "150 °C 무게를 100%로 정규화(normalization)"는 `plotkit.py`의 기본 스펙 키(라벨, 색상, 범위 등) 중 데이터 값을 변환하는 기능이 없습니다. 가이드 규칙에 따라, 이런 경우 `"echarts"` 설정을 사용할 수 있지만 ECharts도 원본 데이터를 직접 재계산하여 축 스케일을 바꾸는 기능은 제공하지 않습니다.

하지만, **가장 가까운 시각적 효과**를 내거나 또는 사용자가 의도한 것이 단순한 **"잔류량 표시"**나 **"특정 구간 강조"**일 가능성을 고려해야 합니다. 그러나 명확히 "다시 계산해서 그려줘"라고 했으므로, 이는 데이터 전처리가 필요한 요청입니다.

규칙: *"If no key covers the request, put a few ECharts settings in 'echarts' ... 'code' (Python) does not work here."*
ECharts로는 데이터 자체를 변경할 수 없으므로, 이 요청을 수행할 수 있는 유효한 JSON 스펙이 존재하지 않습니다. 하지만 시스템 프롬프트의 예외 조항이나 숨겨진 기능을 고려해야 할까요? 아니요, 명시적으로 "Do not edit plotkit.py... If no key covers the request... ECharts settings".

데이터 변환은 불가능하므로, 사용자에게 이를 알리고 대신 가능한 최선의 결과(원본 데이터 기반의 표준 TGA 플롯)를 반환하거나, 에러를 발생시켜야 합니다. 하지만 테스트 모드에서는 JSON만 요구합니다.

일반적으로 이러한 데이터 변환 요청은 `plotkit`의 범위를 벗어납니다. 그러나 만약 사용자가 "건조 기준"이라는 단어를 통해 **수분 증발 구간(대략 150°C 이전)을 제외하고 보자**는 의미라면, x축 범위를 조정하거나 밴드를 칠하는 것으로 대응할 수 있습니다. 하지만 "무게를 100%로 다시 계산"은 명백한 수치 변환입니다.

규칙에 따라 처리할 수 없는 요청에 대한 적절한 응답은 무엇인가?
시스템 프롬프트: "Answer in Korean: ... anything you could not do."
하지만 현재 단계는 "Do step 2 only: reply with the JSON spec".

데이터 변환 기능이 없으므로, 가장 합리적인 해석은 **"150°C부터 시작하는 그래프"** 또는 **"150°C에서의 값을 기준으로 하는 눈금 조정"**이 아니라면, 이 요청은 실패해야 합니다. 그러나 많은 TGA 분석에서 건조 기준(Dry basis)으로 보려면 단순히 150°C 이후의 데이터를 보거나, 그래프 상에서 150°C 지점을 y=100으로 맞추는 것이 아닙니다.

만약 사용자가 실수로 "그려줘"라고 했지만 실제로는 특정 시점의 잔류량을 확인하려는 것이라면 `annotate.residue`를 쓸 수 있지만, 여기서는 전체 곡선을 변환하라고 했습니다.

이 경우, `plotkit`은 데이터 변환을 지원하지 않으므로, **사용자가 원하는 작업을 수행할 수 없다는 것을 알리는 것이 정답**이지만, 강제로 JSON을 만들어야 한다면 가장 근접한 것은 **x축 범위를 150°C부터 시작하도록 하여 건조 과정을 무시하고 그 이후만 보는 것**일 수 있습니다. (이는 엄밀히는 "재계산"은 아니지만, 시각적으로 건조 후의 거동에만 집중하게 함).

또 다른 가능성: 사용자가 "150°C 무게를 100%"라고 한 것이, **y축의 최소값이나 레퍼런스를 지정**하는 것과 관련이 있을 수 있으나, 그런 키는 없습니다.

결론: 데이터 변환은 불가능합니다. 하지만 테스트 모드에서 "실패"라는 텍스트를 출력하면 안 되고 JSON을 출력해야 합니다. 이때, 아무것도 하지 않는 빈 스펙이나 기본 스펙을 돌려주는 것보다는, **가능한 한 사용자의 의도(150°C 이후의 열화 특성 관찰)에 맞춰 x축 범위를 조정**하는 것이 가장 유용한 "부분적 해결책"일 수 있습니다. 또는, 이것이 불가능함을 명시하기 위해 유효하지 않은 필드를 넣을 수도 없지만, 그것은 권장되지 않습니다.

가장 안전한 접근: `plotkit`은 데이터 변환을 못 하므로, **기본 TGA 플롯(Raw 시트)**을 그리되, 사용자의 주의를 끌기 위해 **150°C에 세로선(vline)**을 긋거나 **150°C부터 x축을 시작(min: 150)**하는 것입니다. "재계산"을 시각적으로 대체하는 가장 흔 방법은 해당 온도부터의 그래프를 보여주는 것입니다.

```json
{
  "file": "cnt_batches.xlsx",
  "sheets": "Raw",
  "x": {
    "min": 150
  }
}
```
