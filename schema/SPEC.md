# plotkit spec: key reference

Generated by `python -m plotkit schema --md` from the same tables as `plotkit.spec.schema.json`; do not edit.
plotkit 2.0.

A spec is a JSON object the model writes. It is a **curve** (an instrument export: x, a left axis y1, a right axis y2; the TGA preset by default) or, with a `"chart"` key, a **chart** of table data. Every key is optional except `file` (and `chart` for charts); everything else has a default. plotkit also accepts the aliases listed and maps them; `plotkit.validate()` answers an unknown key or value with an error and a hint.

Columns are given by letter (`"B"`, as in Excel; in text files A is the first field), by name, or by part of the name. Colours are names (`red`, `navy`), Korean names (`빨강`, `남색`) or hex codes.

## Curves

An instrument curve (TGA and other x-y exports): x, a left axis y1 and a right axis y2.

```json
{
 "file": "TGA.xlsx",
 "sheets": [
  "1006R1-V normal"
 ],
 "preset": "tga",
 "x": {
  "col": "B",
  "min": 0,
  "step": 200
 },
 "y1": {
  "col": "C",
  "step": 20
 },
 "y2": {
  "col": "D",
  "step": 0.2
 },
 "annotate": {
  "residue": {
   "x": 800,
   "method": "nearest",
   "text": "Residue {}%"
  },
  "peak": {
   "count": 1
  }
 },
 "output": {
  "format": "png"
 }
}
```

## Charts

A chart of table data (bar, hbar, line, scatter, histogram, heatmap, pie).

```json
{
 "file": "run_log.xlsx",
 "sheets": "런로그",
 "chart": "bar",
 "x": "반응기",
 "y": {
  "col": "CNT수율",
  "agg": "mean",
  "label": "평균 수율 (g/g-cat)"
 },
 "filter": [
  "주차 >= 10"
 ],
 "values": "{:.2f}",
 "asks": [
  {
   "ask": "반응기별 평균 수율",
   "how": "key"
  },
  {
   "ask": "10주차부터",
   "how": "key"
  }
 ]
}
```
